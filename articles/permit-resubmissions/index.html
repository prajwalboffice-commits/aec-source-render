Architectural Documentation

How Can Architecture Firms Reduce Permit Resubmissions Caused by Incomplete Drawing Packages?

A six-person firm submitted the architectural permit drawings for a 12,000 sq ft, two-story medical office. Three weeks later nine review comments came back, and every one was about something missing or something that disagreed with another sheet. Since then the firm treats each package the same way: check it against the authority’s current requirements, coordinate the information across sheets and look at every revision before issue. A coordinated set lets the reviewer assess the proposed work without chasing missing information.

What the nine comments said

The ground floor plan had no dimensions on the waiting room and no room labels in the back corridor. The east elevation still showed the window layout from two revisions ago. A 3 ft level change at the stair had no section, so the reviewer couldn’t check the heights. A detail callout pointed to sheet A-501, which wasn’t in the set, and the door schedule listed 14 doors while the plan showed 16.

Each sheet looked acceptable on its own. The incomplete architectural drawings only showed up when the reviewer read the set as a whole, which is when the permit review comments arrived.

Starting with the authority’s checklist

Before the next permit set, the firm pulled the city’s current submission checklist. Requirements change with the jurisdiction, the project type and the scope, so a checklist from one permit doesn’t carry over to the next. The firm listed the required drawings, supporting documents, scales, signatures and project information. It then built a sheet register and matched each of those permit submission requirements to a specific sheet or document. Items that didn’t apply were confirmed with the city, and whatever the owner or the consultants still owed went on a separate list.

Reading plans, elevations and sections together

A second person read the set as one package. Dimensions, room names, openings, floor levels and building heights had to agree from one view to the next. Section and elevation callouts had to point at the right locations, every detail needed a reference and every schedule had to match the latest plan. The same pass covered title blocks, sheet numbers, scales and revision dates.

Controlling changes before the set goes out

The east elevation had been wrong because the plan changed late. The revised plan was ready, but its elevation, section and schedule still showed the old layout. So the firm now keeps one drawing register. Each of the architectural drawing revisions is logged along with every sheet it touches, and nothing goes out until those sheets are updated. Before issue, someone compares the final PDFs with the current source files and pulls out any superseded sheets.

Adding an independent quality check

Before submission, a second reviewer goes through the set with the authority’s checklist and the firm’s own QA list. These drawing quality checks look at completeness and consistency, which is exactly what the author stops seeing after a month on the same drawings. When several packages compete for production time, the firm can send defined permit set drawings to external architectural drafting services, one way to get architectural permit drawing services without growing the team. Design decisions, code interpretation and final approval stay with the responsible architects, and the drafting team gets current files and clear instructions.

Submitting a coordinated package

The permit drawing package for the clinic’s second phase went in complete for that city and that scope, consistent across sheets and built on the latest approved design information. A checklist, controlled revisions and an independent review caught the gaps before the city did, and the project didn’t lose another three weeks to a resubmission.
